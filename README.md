#  PetCol | Sitio Web Institucional

**PetCol** es un sitio web institucional y de presentación diseñado para un negocio local del sector de mascotas. Este proyecto se enfocó en crear una interfaz limpia, atractiva y directa al grano para cumplir con los requerimientos de visibilidad comercial y una demostración académica.

---

## Características Principales

* **Diseño Institucional:** Estructura clara para mostrar la propuesta de valor del local, servicios y productos orientados al cliente final.
* **Optimización y Ligereza:** Construido con código nativo y optimizado para garantizar tiempos de carga ultra rápidos.
* **Diseño Responsivo:** Adaptado para verse de forma impecable tanto en dispositivos móviles como en computadoras de escritorio.

---

## Stack Tecnológico

El proyecto está desarrollado con tecnologías web fundamentales, garantizando un mantenimiento sencillo y un rendimiento óptimo:
* **HTML5** (Estructura semántica)
* **CSS3** (Estilos personalizados y diseño adaptable)
* **JavaScript** (Interactividad básica y dinamismo en la interfaz)
